How to launch BYTEK:
1. download the newest version of python from https://www.python.org/downloads/windows/
2. install python
3. return to this folder, right-click 'main.py'
4. select "open with python"

Q: Want to share BYTEK with others? Which files are safe to delete?
If you want to delete some files without the risk of losing the contents,
A: you can delete files "help.txt, help2.txt, howToGetTheGame.txt, 
howToPlay.txt, releaseBreadInSchool.txt, README.txt"
